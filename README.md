# BBO EasyStore Converter

BBO EasyStore Converter ialah aplikasi untuk menukar data produk daripada PrestaShop kepada format import EasyStore.

## Status

Current Version : v0.1.0

## Features

- Read PrestaShop Product CSV
- Read ps_product_lang.csv
- Generate EasyStore CSV
- Batch Processing (Coming Soon)
- GUI (Coming Soon)
